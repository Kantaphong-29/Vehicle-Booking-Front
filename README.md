# Vehicle Booking Frontend
ระบบบริการจองรถตู้ออนไลน์ คณะศึกษาศาสตร์ มหาวิทยาลัยศิลปากร (Frontend)

Stack: React + Vite + Tailwind CSS + React Router

## การติดตั้ง

```bash
npm install
npm run dev
```

เว็บจะรันที่ `http://localhost:5173` และเรียก backend API ที่ `http://localhost:5000`
(ต้องรัน backend ที่ทำไว้ก่อนหน้าคู่กันด้วย — ดู `vehicle-booking-backend`)

หากพอร์ต backend ไม่ใช่ 5000 ให้แก้ค่า `BASE_URL` ใน `src/api/client.js`

## แนวคิดการออกแบบ (Design Tokens)

**สีหลัก** — อ้างอิงสีประจำคณะศึกษาศาสตร์ (สีน้ำเงิน) และสีทองของครุยวิทยฐานะ:
- น้ำเงินเข้ม `#141F38` / `#1B2A4A` — sidebar, ปุ่มหลัก
- ทอง `#C9A227` — accent, สถานะ active
- โทนกระดาษ `#F7F3EA` / `#FBF9F3` — พื้นหลัง, การ์ด (สื่อถึงเอกสารกระดาษที่ระบบนี้เข้ามาแทนที่)
- เขียวหม่น/แดงอิฐ/เหลืองทอง — สถานะ อนุมัติ/ปฏิเสธ/รออนุมัติ

**ตัวอักษร**
- หัวข้อ: Noto Serif Thai (ความขรึมขลังแบบสถาบันการศึกษา)
- เนื้อหา: IBM Plex Sans Thai
- ตัวเลข/รหัสอ้างอิง: IBM Plex Mono

**Signature element** — "ตราประทับสถานะ" (`.stamp` ใน `src/styles/index.css`) ออกแบบให้มีลักษณะคล้ายตราประทับบนเอกสารราชการแบบเดิม เอียงเล็กน้อย มีเส้นขอบสองชั้น สื่อถึงการเปลี่ยนผ่านจากระบบกระดาษสู่ระบบดิจิทัลตามที่ระบุในบทที่ 1 ของโครงงาน

## โครงสร้างหน้า

| หน้า | Path | คำอธิบาย |
|---|---|---|
| เข้าสู่ระบบ | /login | |
| สมัครสมาชิก | /register | |
| ภาพรวม | / | สถิติคำขอ + รายการล่าสุด |
| ยื่นคำขอใช้รถ | /new | เฉพาะ role USER |
| คำขอของฉัน/ทั้งหมด | /bookings | filter ตามสถานะได้ |
| รายละเอียดคำขอ | /bookings/:id | อนุมัติ/ปฏิเสธ/มอบหมายรถ-คนขับ (STAFF/ADMIN), ยกเลิก (เจ้าของ) |
| รออนุมัติ | /approvals | เฉพาะ role STAFF/ADMIN |

## หมายเหตุ

- ปุ่ม "ยื่นคำขอใช้รถ" และ "รออนุมัติ" จะแสดง/ซ่อนอัตโนมัติตาม role ของผู้ใช้ที่ login
- role เริ่มต้นของผู้สมัครใหม่คือ USER เสมอ ต้องเปลี่ยนเป็น STAFF/ADMIN ผ่านฐานข้อมูล หรือ endpoint `/api/users/:id/role` (ต้องมี ADMIN อยู่ก่อนแล้ว)
